# 🎵 TUNEXA

**Your Music. Your Vibe. Your World.**

TUNEXA is a music streaming web app built as a college project using React and Vite. It provides a simple, modern interface for exploring music, managing favourites, and experiencing a demo music player.

## ✨ Features

- 🎧 Music player with play and pause controls
- 🔍 Search songs
- 🌐 Browse songs by language
- ❤️ Add songs to favourites
- 🎵 Music library
- 🎙️ AI Song Studio demo interface
- 💎 Free and Premium demo modes
- 📱 Dark-themed music interface

## 💎 Free & Premium Demo

TUNEXA includes a demonstration of two plans:

- **Free:** Includes sample advertisements.
- **Premium:** Demonstrates an ad-free experience.

*These are demo features. No real payments or subscriptions are processed.*

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/LOKESH0-DE/TUNEXA.git
   ```

2. Open the project folder:

   ```bash
   cd TUNEXA
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev

5. Open the local URL shown in your terminal.

## 📌 Project Status
